# Persönliche Ideen und Gedankensammlungen

**Status:** nichtkanonisch
**Sichtbarkeit:** öffentlich einsehbar
**Zweck:** unveränderte Rohnotizen und persönliche Ideensammlungen des
Repository-Eigentümers

## Wichtiger Vertraulichkeitshinweis

Das FolioTone-Repository ist öffentlich. Dieser Bereich ist nur im Sinn von
„persönliche Notizen“ privat; er besitzt keinen technischen Zugriffsschutz.
Ein Verschieben innerhalb des Repositorys entfernt Inhalte außerdem nicht aus
der Git-Historie.

Hier dürfen deshalb niemals Secrets, Zugangsdaten, private Host- oder
Sammlungspfade, reale Sammlungsmetadaten, Runtime-Berichte, Passwörter,
personenbezogene Inhalte oder andere vertrauliche Daten abgelegt werden. Für
tatsächlich vertrauliche Gedanken ist ein separates privates Repository oder
ein nicht versionierter Bereich unter der vorgesehenen `C:\rep`-Struktur
erforderlich.

## Autoritätsgrenze

Dateien in diesem Verzeichnis sind:

- keine Architekturentscheidung;
- keine Implementierungsanweisung;
- keine Backlog- oder Statusquelle;
- nicht auf Aktualität, Widerspruchsfreiheit oder Quellenqualität garantiert.

Sie dürfen Wiederholungen, Recherchefragmente, Gesprächsartefakte, veraltete
Versionsangaben, unbelegte Empfehlungen und noch nicht entschiedene
Alternativen enthalten.

Eine Idee wird erst verbindlich, wenn sie kollisionsgeprüft in eine
kanonische Vision, ein Planungsdokument, `BACKLOG.md` oder eine akzeptierte
ADR übernommen wurde. Die bereinigte strategische Einordnung steht in:

- [Evidence-driven Collection Intelligence](../../vision/EVIDENCE_DRIVEN_COLLECTION_INTELLIGENCE.md)
- [Future Capability Map](../../planning/FUTURE_CAPABILITY_MAP.md)
